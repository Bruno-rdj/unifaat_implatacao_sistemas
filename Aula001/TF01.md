# TF01 - Deploy Manual e Configuração de Servidor Web
**Disciplina:**  Implementação de Software 
**Curso:** Análise e Desenvolvimento de Sistemas - UniFAAT  
**Aula:** 01 - Deploy Manual em Linux Local  
**Valor:** 1,5 pontos  
**Prazo:** 1 semana após a aula

## Objetivo

Demonstrar domínio dos conceitos fundamentais de deploy manual, configuração de servidor web e gerenciamento de permissões no Linux.



## Tarefa

Configurar um servidor web Nginx personalizado com página institucional de uma empresa fictícia, aplicando boas práticas de segurança e documentação.

## Especificações

### Empresa Fictícia
Crie uma empresa fictícia com:
- **Nome da empresa**
- **Ramo de atividade**
- **Missão e visão**
- **Serviços oferecidos**

### Requisitos Técnicos

**1. Configuração do Nginx:**
- Instalar e configurar Nginx
- Configurar permissões corretas (sem uso desnecessário de sudo)
- Nginx deve iniciar automaticamente no boot

**2. Página Web Personalizada:**
- HTML5 semântico e responsivo
- CSS personalizado (não usar frameworks)
- Informações da empresa fictícia
- Seção "Sobre a Empresa"
- Seção "Serviços"
- Seção "Contato" com formulário (apenas frontend)

**3. Configuração de Virtual Host:**
- Criar configuração personalizada do Nginx
- Configurar logs de acesso e erro personalizados
- Implementar página de erro 404 customizada

**4. Segurança:**
- Configurar permissões adequadas nos arquivos
- Documentar as configurações de segurança aplicadas

## Como Executar

### Pré-requisitos
- Ubuntu 20.04+ ou similar
- Acesso sudo

### Instalação
```bash
# Clone o repositório
git clone [URL_DO_SEU_REPO]
cd TF01

# Execute o script de instalação
chmod +x scripts/install.sh
./scripts/install.sh
```

### Acesso
- Site principal: http://localhost
- Páginas disponíveis:
  - / (Home)
  - /sobre.html
  - /servicos.html
  - /contato.html

## Configurações Aplicadas
- Nginx configurado com virtual host personalizado
- Logs personalizados em /var/log/nginx/
- Permissões configuradas para usuário atual
- Página 404 customizada

## Comandos Úteis
```bash
# Verificar status do Nginx
sudo systemctl status nginx

# Ver logs de acesso
sudo tail -f /var/log/nginx/access.log

# Ver logs de erro
sudo tail -f /var/log/nginx/error.log
```
